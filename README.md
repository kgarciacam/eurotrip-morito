# 🇪🇺 Eurotrip Morito 2026

Mini web-app de viaje para Kathy + Morito.

## Publicarla con GitHub Pages

1. Crea un repositorio nuevo en GitHub, por ejemplo `eurotrip-morito`.
2. Sube `index.html`, `style.css` y `app.js`.
3. En el repositorio entra a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`.
6. Guarda.
7. GitHub te dará un enlace tipo:
   `https://TU-USUARIO.github.io/eurotrip-morito/`

## Importante

No subas pasaportes, boarding passes, QR ni documentos privados al repositorio.
Esos archivos deben permanecer en Google Drive y la app puede enlazar a ellos.

## Para actualizar la app

La información principal está en `app.js`, en las listas `itinerary`, `docs` y `hotels`.
